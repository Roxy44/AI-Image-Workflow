# Разборы ошибок

Один файл — один разбор, имя `ГГГГ-ММ-ДД-краткий-слаг.md`. Формат и когда писать:
`.cursor/rules/retrospective.mdc`.

Пишите на языке общения проекта.

Шаблон:

```markdown
# Короткий заголовок

- **Симптом:** что наблюдали.
- **Причина:** настоящая причина, а не первый подозреваемый.
- **Исправление:** что изменили, с путями к файлам.
- **Вывод:** одно предложение для будущего агента.
- **Область:** где применимо (модуль, слой, весь репозиторий).
```

Один и тот же вывод в третий раз → правило проекта в `.cursor/rules/project/`, не четвёртая
заметка.
