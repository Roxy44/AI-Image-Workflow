# Память проекта

Рабочая память команды и агента. Эти файлы **не** попадают в контекст автоматически —
агент открывает их по конституции **M-2** / **M-4** или по просьбе. Объём здесь не стоит
токенов в каждой сессии.

Пишите записи на **языке общения** проекта (см. `project/stack.mdc`).

| Файл                | Для чего                                                                |
| ------------------- | ----------------------------------------------------------------------- |
| `tasks.md`          | Текущие и отложенные задачи, follow-up после временных решений          |
| `knowledge-base.md` | Факты, которых нет в коде: договорённости, внешние системы, ограничения |
| `ideas.md`          | Идеи, по которым ещё нет решения                                        |
| `lessons/`          | Разборы ошибок: симптом, причина, вывод (формат в `retrospective.mdc`)  |

## Правила

1. Коротко и по факту. Это не дневник — каждую запись кто-то прочитает позже.
2. Устаревшее удаляйте или помечайте. Неверная память хуже отсутствующей.
3. Один и тот же вывод в третий раз → правило в `.cursor/rules/project/`, не четвёртая
   заметка.
4. Секретов, токенов и персональных данных здесь быть не должно.
